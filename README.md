Запуск сайта
1. Зайди в папку warehouse-server.
2. Открой командную строку (в строке пути напиши cmd).
3. Введи команду: "npm start" .
4. Ты должен увидеть: ✅ Сервер склада запущен!. Важно не закрывать окно
5. Открой любой браузер (Chrome, Edge).
6. В адресной строке введи: `http://localhost:3000`. Откроется сайт


Настройка связи с Телефоном
1. Тебе нужно узнать IP-адрес твоего компьютера. В том же черном окне (или открой новое через cmd) введи: `ipconfig`.
2. Ищи строку IPv4-адрес. Он выглядит примерно так: 192.168.1.45. Запомни его.

Работа в Приложении
1. Запусти приложение на Android-телефоне (телефон и компьютер должны быть в одной сети Wi-Fi).
2. В поле "IP сервера" введи тот самый адрес (например, 192.168.1.45).
3. Нажми кнопку "Обновить список задач". Если всё верно, в приложении появятся те же задачи, что ты видишь на сайте (Приемка, Сборка).
